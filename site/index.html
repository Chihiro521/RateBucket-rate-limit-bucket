04常见问题

你可能想知道

安装与用量显示的几个常见问题。

需要登录另一个账号吗？+

不需要。安装后，在已经登录的支持网站上使用即可。RateBucket 没有单独的账号系统。

每个平台都能看到精确剩余次数吗？+

显示内容取决于平台提供的信息：有的提供次数，有的提供百分比或共享额度池。部分信息属于本地估算或未校准读数，组件会标明来源与状态。

暂时看不到额度，怎么办？+

先确认已登录平台，再尝试组件的刷新按钮。平台接口可能变化；如果问题持续，可以在 GitHub 提交问题，附上平台名称和组件提示。

可以在手机或其他浏览器上使用吗？+

目前主要在桌面 Chrome / Chromium 浏览器上验证。官网可以用手机浏览，扩展本身尚未正式支持手机、Firefox 或 Safari。

它是各家 AI 平台的官方扩展吗？+

RateBucket 是独立的开源项目，与所支持的 AI 平台没有隶属或官方合作关系。代码采用 MIT 许可证，欢迎通过 GitHub 了解和参与。
