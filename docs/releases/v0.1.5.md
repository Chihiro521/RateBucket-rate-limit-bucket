# RateBucket v0.1.5 更新公告

2026 年 10 月 13 日

这次新增 Muse 额度查看，改善首次查询和折叠浮窗的显示体验。

## Muse 额度查看

- 显示每周额度的已用／剩余百分比和重置倒计时。
- 额外词元余额使用 Muse 每次返回的官方文字，随使用和充值变化，并显示“从不过期”。
- 打开页面自动查询，可见时每分钟刷新；隐藏时暂停，切回页面检查是否需要更新，也可手动刷新。
- 登录失效时清空读数；临时请求失败时显示上次读数及查询时间。

## 显示与查询修复

- Muse 折叠条保持单行，收紧平台名与剩余额度之间的间距。
- 优先识别后加载的应用脚本；四路扫描独立运行，找到接口编号立即停止，避免无关慢脚本拖住首次查询。
- 超时提示区分接口识别、请求和响应读取阶段。
- ChatGPT 订阅倒计时在同一账号内持续保留，并每秒更新。

从 GitHub v0.1.3 升级的用户还会获得 v0.1.4 的独立额度刷新、缓存隔离和界面状态保持等改进，完整记录见 [CHANGELOG](../../CHANGELOG.md)。

## 安装与更新

- Chrome Web Store 安装的版本，在商店审核并上线后通过浏览器更新。
- GitHub ZIP 用户下载同版本压缩包，解压后在扩展管理页加载或重新加载扩展，再刷新 AI 网站。
- 新增 Muse 站点访问范围：`https://muse.ai/*`。

## 验证

- 149 项测试通过，TypeScript 检查和扩展构建通过。
- Muse 登录态接口实测成功；周额度、重置时间和官方额外余额文字已核对。
- 桌面及窄屏界面检查通过，并覆盖慢脚本、接口编号更新、隐藏页面暂停、登录失效和原响应完整性。

## English

RateBucket v0.1.5 adds Muse weekly quota and reset countdowns, plus dynamic official extra-token balance text. Visible Muse pages refresh once per minute and support manual refresh. Authentication failures clear readings; temporary failures preserve the last successful data and check time.

The compact Muse widget keeps its single-line layout with tighter spacing. Four independent discovery workers prioritize application chunks and stop as soon as the subscription action is found. Timeout messages identify the failing stage. ChatGPT subscription countdowns remain available within the same account and update every second.

Validation: 149 tests passed; TypeScript and extension builds passed. The Chrome Web Store and GitHub packages use the same version and ZIP.
