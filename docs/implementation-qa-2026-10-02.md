# 额度模块与旧 UI 体验优化：本地验收

日期：2026-10-02。此记录对应本轮实现，不覆盖或改写此前接口研究记录。

## 实现结果

- 旧配色、人物挂件、卡片装饰与平台分组保留；UI 公共优化覆盖六个平台。
- ChatGPT 默认主动查询仅使用 conversation/init、wham/usage、files/library/storage/usage。
- 并发逐项更新、每接口独立的 30 秒刷新与失败退避、在途请求复用、操作后补查。
- 文件库容量按 GiB 显示；可用重置机会直接读取 WHAM，不增加专用查询。
- 显式百分数字段不再使用 0 到 1 的比例猜测；相对截止时间按接收时刻固定。
- 图像读数保留并标未校准，明确阻断优先；可选 Credits 与重置机会为零不触发整体耗尽提示。
- 每项成功接收时间独立保留；失败不刷新旧读数时间，账号缓存按哈希范围隔离。
- 面板与额度行采用稳定节点协调；时间文字单独更新，滚动、焦点、设置选择及拖动节点保持。
- IP 检测代码、配置界面、请求和专用域名权限移除；旧设置只按键名一次性清除。
- 语言设置、ChatGPT 账号状态、其他平台解析保留；未新增近七天图像统计。

## 后续修复：额外的 Chatpass Windows

根据实际截图，普通五小时窗口与每周窗口正常，但通用解析器还把 chatpass.windows 子限额显示成了两条额外英文词条。本轮只过滤 ChatPass 子树，不改变主窗口的数值、周期或其它已验证的模型限额。

解析、缓存合并、缓存恢复与显示层均排除该类词条，旧缓存不会继续保留它们。新增四项回归测试；最终 npm test 为 17 个文件、106 项测试通过，npm run build 与 git diff --check 均通过。构建仍在 dist/，未发布。

按用户要求完整移除该卡片、难度评分、相关 fetch/XHR 观察模块、事件订阅、样式和文案。新增独立迁移标记，已经完成上一轮迁移的用户也会清除旧的状态和观察记录；额度缓存和语言偏好不受影响。
